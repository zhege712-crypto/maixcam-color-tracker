智能搬运 · 上位机（便携版）
================================================================

一、怎么运行
  1. 双击 启动上位机.bat
  2. 界面出现后，左下角“串口”按钮点开选 COM 口（如 COM5）
  3. 点“连接”，相机开始上报就会滚动刷新
  4. 没有相机时想先看界面：命令行里执行
         启动上位机.bat --demo
     或者在文件夹地址栏输入 cmd 回车，再敲上面这句

  注意：这个黑窗口是启动器，关掉它等于退出上位机。


二、需要装什么
  什么都不用装。
    · pyserial 已经随包携带（app\serial 目录），不需要 pip install
    · 只需要这台电脑上有 Python 3.8 以上（32/64 位都行）
  检测有没有 Python：按 Win+R 输入 cmd 回车，敲
         py -3 -V
  显示 3.8 以上就说明能用。
  没有 Python 的话，到 https://www.python.org/downloads/ 下载安装，
  安装第一页务必勾选 “Add python.exe to PATH”。


三、界面速查
  · 串口行：[无串口 ▾] [115200] [连接]
      - 点串口名切换 COM 口，点波特率按钮可填任意值（300 ~ 4000000）
      - 正连着时改波特率会自动按新速率重连
  · 底部：[重扫] [原始帧] [清空]
      - 重扫：重新枚举串口
      - 原始帧：打开后只显示收到的十六进制字节，方便排查波特率不对/噪声
      - 清空：清空日志
  · 颜色 / 形状 / 坐标卡片：实时目标信息（坐标为 640×480 参考像素）
  · 录制 CSV：开始/停止把帧统计写成 captures\gs-日期时间.csv
  · PING：给相机发一帧下行命令，测链路是否通


四、常见问题
  1. 双击后黑窗口一闪就没
     说明 Python 没找到或者太旧。在文件夹里按住 Shift 右键 ->
     “在此处打开 PowerShell 窗口”，执行 .\启动上位机.bat 就能看到具体报错。

  2. 串口列表是空的
     · USB 转串口没插好 / 驱动没装（设备管理器看有没有黄色感叹号）
     · 点底部“重扫”再看
     · 换 USB 口、换根数据线（很多线只能充电不能传数据）

  3. 连上了但一直没数据
     · 打开“原始帧”：只有乱码字节 = 波特率不对，改波特率再试
     · 什么都没有 = 相机没在发 / TX 没接对（相机 A19 是 TX，要接模块 RX，并且共地）
     · 也不要接相机的 A16/A17，那是调试串口

  4. 字太小 / 窗口太大
     界面会按你的屏幕 DPI 和分辨率自动缩放。换显示器、改缩放比例，
     重新双击启动即可。


五、文件夹里都是什么
  启动上位机.bat          启动器（找 Python、检查环境、拉起界面）
  使用说明.txt            本文件
  app\ground_station.py   主程序（Material You 界面 + 串口收发 + 帧统计）
  app\protocol.py         协议编解码（v4：上行 20 字节 / 下行 4 字节）
  app\serial\             pyserial 3.5，随包携带，BSD 许可
  captures\               “录制 CSV”后才会生成，记录放在这里


六、命令行参数（给会敲命令的人）
     启动上位机.bat --port COM5            启动即连接该串口
     启动上位机.bat --baud 9600            启动时用这个波特率
     启动上位机.bat --demo                 演示模式，不需要任何硬件
     启动上位机.bat --port COM5 --baud 9600


七、协议速查（v4）
  上行 20 字节：AA AA BB BB | 存在 | 颜色 | 角度 | X | Y | 宽 | 高 | 校验 | FF FF EE EE
  下行 4  字节：AA BB | 命令 | FF          命令 1=红 2=绿 3=蓝 7F=PING
  详细定义见仓库里的《相机_主控串口通信协议_定稿.md》
